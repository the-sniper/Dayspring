# Employee portraits

Drop an image here named by ROLE ID (not character name) and it instantly
replaces the generated avatar everywhere in the app:

  atlas.png     -> Dumbledore      radar.png    -> Hermione
  sentinel.png  -> Ginny           ledger.png   -> Gringotts
  compass.png   -> Ron             quill.png    -> Luna
  pulse.png     -> Percy           herald.png   -> Hedwig
  forge.png     -> Fred & George   mason.png    -> Hagrid
  probe.png     -> Snape           vigil.png    -> Dobby
  archive.png   -> Neville

png / jpg / jpeg / webp / svg all work. Square images look best (they render
in rounded tiles). Generate them with any image tool — e.g. "portrait of a
wise old wizard headmaster, warm light, square icon" per character.
